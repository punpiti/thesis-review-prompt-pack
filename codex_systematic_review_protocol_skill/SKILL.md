# Systematic Review Protocol

Use this skill when the literature task is formal enough to need a systematic
or scoping review protocol. For ordinary thesis related work, use
`thesis-literature-review` instead.

## Core Rule

Do not fabricate search results, eligible studies, PRISMA counts, or evidence
strength. This skill designs or audits the protocol; it does not pretend the
review has been run.

## What To Check

1. Review question
   - PICO/PEO/SPIDER or field-appropriate framework
   - scope, population/context, intervention/exposure/concept, outcome

2. Search strategy
   - databases and source types
   - search terms by concept
   - controlled vocabulary where relevant
   - date/language/document-type limits and rationale

3. Eligibility criteria
   - inclusion/exclusion criteria
   - study design types
   - population/context boundaries
   - outcome/measure requirements

4. Screening and extraction
   - title/abstract/full-text screening
   - duplicate handling
   - reviewer roles and conflict resolution
   - extraction fields

5. Quality/risk-of-bias and synthesis
   - appropriate appraisal tools
   - narrative synthesis or meta-analysis criteria
   - heterogeneity, sensitivity, subgroup analysis when relevant
   - certainty of evidence if applicable
